What I'm Working On

HobbyBloom

HobbyBloom is an interactive interface that breaks down the entrance-barrier to start a new hobby. This platform offers an intuitive, user-centered designed to help college students discover, track, and share their personal development journey across a wide variety of fulfilling hobbies.
Restaurant Rover

A restaurant discovery interface designed to help users easily browse restaurants worldwide by cuisine and location. Developed during my time at Barcelona Code School, Restaurant Rover features HTML, CSS, JavaScript and React elements.
Roose & Vine

A database driven restaurant application designed to organize and display restaurant and menu information in a clear, user-friendly way. Created for INFO-I494 at Indiana University, built using HTML, CSS, PHP, and SQL.
